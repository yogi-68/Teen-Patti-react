# Audio Assets

Place the following audio files here:
- `button-click.mp3` - Sound for button clicks
- `background-music.mp3` - Background music loop
- `winner.mp3` - Winner celebration sound

You can get free sounds from:
- https://freesound.org/
- https://mixkit.co/free-sound-effects/

Recommended settings:
- Format: MP3
- Button click: Short (< 0.5s), light click sound
- Background music: Looping, soft casino/card game music
- Winner: Celebration sound (2-3s)
